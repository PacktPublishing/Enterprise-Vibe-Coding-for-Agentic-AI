# Chapter 2 — Agentic AI and the New Way We Work

Companion assets for **Chapter 2: Agentic AI and the New Way We Work** from *Agentic Development in Practice*.

Chapter 2 builds the conceptual foundation: what an AI agent actually is (model + perception + reasoning + tools + memory), how agents organise into **agentic systems** with autonomy on a gradient, the **single-surface** paradigm enabled by MCP and A2A protocols, and the three-phase progression of human-agent collaboration — from human-first efficiency to autonomous agents governed by humans. It introduces "vibe working" as the broader expression of vibe coding beyond the IDE and defines the **relationship contract** between humans and agents.
