From Models to Agents

An LLM on its own responds. An agent is what you get when you wrap a model in the machinery it needs to do work in the real world. Four capabilities make the difference:

👁️
Perception
Read context beyond the prompt — files, APIs, repos, databases
🧠
Reasoning
Decompose goals into plans, choose between options, revise
🔧
Tool Use
Call APIs, run scripts, open PRs, send messages
💾
Memory
Remember across steps, sessions, and days

Agent Architecture — Building Blocks

Click each block to explore:

💬 User Experience / Trigger
The interaction point: a chat interface, API call, workflow event, or scheduled task that initiates the agent.
📜 System Message (Instructions)
The agent's "job description" — role, behavior, constraints, tone, objectives, and decision boundaries.
🎛️ Orchestrator
Coordinates execution: reasoning steps, tool calls, memory access, retries, routing between sub-agents. Examples: LangGraph, Microsoft Agent Framework, OpenAI SDKs.
📚 Knowledge Layer
Enterprise knowledge, documents, vector databases, conversation history — grounding the agent in relevant context.
⚙️ Tools / Actions Layer
APIs, databases, workflow engines, email, DevOps platforms, MCP-connected services — how the agent interacts with the world.
🛡️ Autonomy Layer
Defines how independently the agent operates: approval boundaries, escalation paths, exception handling, operational trust.
🧬 Foundation Models
The "brain" — LLMs, multimodal models, embedding models, or specialised models depending on the workload.

From Agent to Agentic AI

If an agent is a single capable worker, agentic AI organises several of them into a system — division of labour, coordination, escalation, and clear responsibility.

Three Common Patterns

👥
Specialist Team
Planner breaks goals into tasks; workers handle research, coding, validation; reviewer checks output
🧰
Tool-Rich Solo Agent
One agent with a large, curated toolbox — sophistication in choosing the right tool at the right moment
🌐
Marketplace of Agents
Agents from different teams/companies discover, negotiate, and collaborate through shared protocols

3

One Surface Changes Everything

For decades, every capability had its own window. Agentic AI decouples the UI from the tools — the user expresses intent into a single canvas, and a network of specialists carries out the work.

The Old Way: Email app → CRM → Calendar → Docs → Chat → IDE

⬇️

The New Way: One intent surface → agents reach into whichever systems are needed

The Protocols Making It Possible

🔌
MCP
Model Context Protocol — tools expose themselves once; any compliant agent can use them. Like HTTPS for AI agents.
🤝
A2A
Agent-to-Agent protocols — agents from different products discover each other and collaborate through shared contracts.

Why it matters: Users learn one place (not twenty). Capabilities matter more than destinations. Apps become engines one layer below the intent surface.

"Vibe Working" — The New Daily Practice

When AI escapes the IDE and enters everyday work, it becomes vibe working: expressing what you want in plain language, agents handle the parts, you show up when judgement is needed.

Three Major Shifts

⏳
Asynchronicity
Delegate to agents, execute in background, review later
🔀
Parallelism
Multiple agents work simultaneously across different tasks and systems
🌊
Ambient Intelligence
Agents monitor triggers continuously, surface only when human input is needed

Three New Challenges

🧭
Tool Selection
Knowing which agent/system to trust for a given task becomes a skill in itself
🌀
Cognitive Overload
Abundance creates paralysis — new models weekly, quality bars rising constantly
💎
Uniquely Human Value
Judgement, taste, trust, leadership, creativity — the new scarce resources
🧠 What does "vibe working" describe?
Only using AI for coding tasks
Working without any structure or governance
Expressing intent in natural language, agents handle execution, humans provide judgement

Three Phases of Human-Agent Collaboration

AI agents first speed it up, then make it cheaper, then change the operating model. Click each phase:

1
Human-First
Efficiency play

The person does almost all the work. AI assists at the edges — accelerating analysis, surfacing recommendations. In dev: the developer types code, AI completes the line. Same cost per decision, ~30-40% time saved.

2
Agent-Led, Human-Supervised
Productivity play

Agents take over well-defined decisions end-to-end. Humans supervise exceptions and approve edge cases. In dev: agents handle tests, scans, docs; developer reviews. Cost per decision drops 60-70%, throughput per person rises 3-4×.

3
Autonomous Agents, Human-Governed
Operating-model play

Agents run entire streams within policy guardrails. Humans govern outcomes, set rules, intervene only on flags. In dev: multiple delivery streams run in parallel; the developer watches a portfolio view. Structural cost reduction.

🧠 In Phase 2, what does the human primarily do?
Write all the code manually
Supervise exceptions and approve edge cases
Set policies and watch KPIs at portfolio level
6

The New Relationship Contract

Not master-and-tool. Not peer-to-peer. It's closer to manager-and-team — with all the responsibilities that implies.

👤
Humans Bring
Direction, taste, accountability, risk absorption, the brief, the "not yet"
🤖
Agents Bring
Breadth, speed, tirelessness, cross-system operation, execution at scale

⚠️ Without the contract: A team of agents without a clear brief, without review, and without an audit trail will reproduce — at higher speed — exactly the problems of Chapter 1.

✅ With the contract: Humans steer. Agents execute. The relationship is explicit: who decides, who builds, what each side is accountable for, encoded in the daily flow of work.

💡 Chapter Takeaway

An AI agent = model + perception + reasoning + tools + memory. Agentic AI organises agents into systems with autonomy on a gradient. When the interface is decoupled from the agents and agents from the tools, users express intent into a single canvas. Software development is vibe working's earliest expression — and what makes it dependable is the human relationship contract layered on top.
