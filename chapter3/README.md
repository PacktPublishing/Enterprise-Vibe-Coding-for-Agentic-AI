# Chapter 3 — Primitives: The Building Blocks of Agentic Development

Companion assets for **Chapter 3: Primitives — The Building Blocks of Agentic Development** from *From Vibe Coding to Enterprise Agentic Development*.

Chapter 3 introduces the **six core primitives** that turn one-off prompting into repeatable engineering: **Instructions** (always-on rulebook), **Prompts** (reusable task templates), **Agents** (named collaborators with scope), **Skills** (packaged domain knowledge), **Hooks** (automated guardrails), and **MCP** (connective tissue). It shows how primitives are composable and surface-agnostic — a single developer request can activate all six layers of guidance, automation, and control behind the scenes.
