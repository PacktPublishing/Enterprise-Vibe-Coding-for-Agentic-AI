Use Cases: Building Agentic Solutions with the HVE Primitives

Three real-world agentic products — Travel Agency, Conversational Shopping, Multi-Channel Marketing — built end-to-end with HVE primitives. Explore the business cases, watch demos, and dive into the code.

1 Use Case 1 — Travel Agency

Orchestration via agent handoffs. Multiple specialists, one seamless conversation.

✈️

SkyBridge Travel — Agentic IT Concierge

A regional online travel agency serving customers across the Middle East. One conversation = one complete trip booking.

▼

🎯 Business Challenge

A customer types "Long weekend in Lisbon, flying from Dubai, walkable near Alfama" — a single request spanning flights, hotels, baggage, loyalty, and payment. The customer expects one conversation; the business needs many specialists working behind the scenes.

🏗️ Orchestration Pattern

🔀 Handoff Pattern

A Concierge (triage) agent owns the conversation and transfers control to Flight/Hotel specialists on explicit customer request. Only one agent talks at a time; handoff log = audit trail.

2 Use Case 2 — Conversational Shopping

Decision support meets commerce. Guide, don't just search.

🛍️

Luxe — AI Personal Shopper

A premium fashion retailer transforming keyword search into a guided buying experience that increases conversion and basket size.

▼

🎯 Business Challenge

Thousands of products, strong traffic, but many customers browse without buying. The agent helps discover products, compare options, and make informed choices — like a knowledgeable sales associate that scales to millions of interactions.

🏗️ Architecture

💬 Single Agent + Tools

One shopping assistant agent with rich tool access: search products, get details, manage cart, view user profile, browsing history. Boundary: the agent advises and builds carts, but payment runs through existing secure commerce systems.

🎬 Demo

🧩 Primitives Used

MCP: SQL Catalog Agent: shopping-tester Hook: catalog-schema-guard

3 Use Case 3 — Multi-Channel Marketing

Content production + governance at scale. Generate, review, localize, approve.

📣

SkillForge — Campaign Generator

A professional training company generating multi-channel campaigns (email, LinkedIn, Instagram, TikTok) with consistency, compliance, and brand governance.

▼

🎯 Business Challenge

New course launches need email campaigns, landing pages, social posts, paid ads, webinar invitations — each requiring different messaging, localization, brand checks, and legal compliance. The bottleneck is not generating content but keeping it accurate, consistent, compliant, and aligned.

🏗️ Orchestration Pattern

📋 Sequential Pipeline

Strategy → Content → Visual → Audience → Performance analysis, then channel adapters (email, Instagram, TikTok, LinkedIn) fan out. Each agent produces strict JSON consumed by the next stage.

🎬 Demo

5 Knowledge Check

Q1: Why is the Handoff pattern chosen for the travel agency?

Because it's the simplest pattern to implement
Because the conversation is single-threaded and the appropriate specialist changes as the topic shifts
Because it allows multiple agents to respond simultaneously

Q2: What is the transaction boundary in the shopping assistant?

The agent handles the full purchase including payment
The agent advises and builds carts, but payment runs through existing secure commerce systems
A human must approve every item added to the cart

Q3: What does the catalog-schema-guard hook prevent?

Customers from adding out-of-stock items to their cart
Agents from accessing the product database directly
Code edits that drift from the approved product catalog schema
