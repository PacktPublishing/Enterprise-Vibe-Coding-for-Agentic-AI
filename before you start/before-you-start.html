How to navigate the assets

1. Read the chapter READMEIt is the local index for the playbook, files, primitives, and runnable examples.
2. Open the landing pageEach chapterN-landing.html is self-contained and works locally or on GitHub Pages.
3. Inspect hidden folders.github/ and .vscode/ contain the reusable agentic-development assets.
4. Run prototypes locallyChapter 6 Python applications need dependencies and local credentials; GitHub Pages serves only static content.

Useful things to know

GitHub Pages is static. It can host the chapter playbooks, images, JavaScript, and video, but it does not execute Flask or other server-side applications.
Spaces need care. Quote paths containing spaces in terminal commands and use %20 when writing URLs.
Examples are starting points. Validate versions, permissions, policies, and data handling before using any primitive or connector in production.
Secrets stay local. Never commit API keys or production credentials. Rotate anything that may have been exposed.
